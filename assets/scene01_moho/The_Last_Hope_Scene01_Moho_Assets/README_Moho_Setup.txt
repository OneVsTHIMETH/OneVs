THE LAST HOPE — SCENE 01 — MOHO ASSETS

Editable SVG vector artwork, 1920x1080.
Shot SVGs are quick complete compositions. Layer_*.svg files are separated visual elements.

Moho workflow:
1. Create a 1920x1080 project at 24 fps.
2. Import SVG assets using File > Import > SVG (menu wording varies by version).
3. Build layers: space behind Earth; fire cracks and smoke above Earth.
4. For city: skyline behind smoke, fire and foreground rubble.
5. Animate layer position, scale and rotation for camera moves and effects.
6. Save from Moho as a native .moho project.

Note: This package contains editable vector assets, not a native .moho file or finished frame-by-frame animation.
