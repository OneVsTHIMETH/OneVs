How scene generation works

  1. Create or select a saved character.
  2. Describe the visual action with text.
  3. Optionally upload an image reference.
  4. Add dialogue and sound instructions.
  5. Generate short clips, then assemble them in the editor.

Free-tier notes

Cloudflare Workers AI currently includes 10,000 Neurons per day on the Free Workers plan. Requests stop when the free daily allowance is exhausted. Models and limits can change; this project uses the free-plan eligible GLM-4.7-Flash text model and FLUX.1 Schnell image model.

For Sinhala speech, the editor uses speech voices already installed in the visitor’s browser/device. Sinhala voice availability depends on the device and browser.
