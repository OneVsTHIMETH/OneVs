How scene generation works

  1. Write your story in the Story field.
  2. Add visual style and creative rules in Overall Direction.
  3. AI plans scenes to fit your target duration.
  4. Click Analyse Story, then map each story character name to a saved Studio character or let AI invent it.
  5. Story එකේ සෑම චරිතයකටම Character Studio හි upload කළ full reference image එකක් තෝරන්න.
  6. AI generation is available only after you connect the relevant custom API in API Manager.
  7. Edit, save and export your storyboard.

Supabase setup

Run the included SQL migration, deploy the Edge Function and set its encryption secret.

One-time setup
  1. Create a new Supabase project.
  2. Run supabase/migrations/20261112_custom_api_vault.sql and then supabase/migrations/20261112_multi_provider_failover.sql in SQL Editor.
  3. Deploy supabase/functions/custom-api-manager.
  4. Set API_ENCRYPTION_KEY as a Supabase Edge Function secret (32-byte base64 key), plus normal Supabase function environment variables.
  5. Configure Supabase URL and anon key in Studio Settings, create/sign in to a user, then save and test each API.

Each endpoint must implement the adapter contract in CUSTOM-API-SUPABASE-SETUP.md. Automatic failover tries the next tested compatible account only for explicit quota / credit exhaustion or HTTP 429. Ambiguous timeouts stop to avoid duplicate paid requests.
