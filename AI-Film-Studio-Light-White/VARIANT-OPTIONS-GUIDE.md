# Multiple generated options per scene

Each scene can keep alternative generated assets instead of overwriting the previous result.

1. **Image options:** Generate the scene image more than once. The editor keeps each take and lets you choose Image 1, Image 2, etc.
2. **Voice options for the same dialogue:** Use the same dialogue row and click Generate another voice option again. The text is unchanged; only the generated voice take changes. Select the preferred Voice option.
3. **Scene video options:** Generate another video take from the currently selected scene image. Select the preferred Video option after generation completes.
4. The chosen assets are shown with their scene. Save scenes after selecting your preferred takes.

Existing project features and the Magic Hour-only video provider are retained. Scene video generation still uses the existing Magic Hour LTX-2.5 / 480p configuration. Multiple generated video takes consume Magic Hour credits individually. Check your balance before generating additional takes.
